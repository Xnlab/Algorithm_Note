# 01. 구현 · 시뮬레이션

## 핵심 아이디어
알고리즘보다 **지문을 정확히 코드로 옮기는 능력**. 방향 벡터, 격자 범위 체크, 회전을 실수 없이 쓰는 게 전부다.

## 이런 문제에서 쓴다
- 지문이 길고 "~한 다음 ~한다" 식의 규칙이 나열됨
- 로봇·뱀·주사위가 격자 위를 움직임
- 배열 회전, 톱니바퀴 회전

## 템플릿 → [template.py](template.py)
- 4방향/8방향 이동 벡터
- 격자 범위 체크
- 2차원 배열 시계/반시계 90도 회전
- 오른쪽으로 회전(방향 전환)

## 자주 하는 실수
- `(x, y)`와 `(row, col)`을 섞어 씀 → **항상 `(r, c)`로 통일**
- 격자 범위 체크를 빼먹음
- 동시에 일어나야 하는 변화를 순차로 바로 반영함 → 새 배열에 결과를 모은 뒤 한 번에 교체
- 2차원 리스트를 `[[0]*m]*n`으로 만듦 (행이 공유됨) → `[[0]*m for _ in range(n)]`

## 대표 문제
| 문제 | 떠올렸어야 할 단서 |
|---|---|
| 백준 14503 로봇 청소기 | 방향 회전 + 격자 이동 |
| 백준 3190 뱀 | 덱으로 몸통 관리 |
| 프로그래머스 키패드 누르기 | 좌표 거리 계산 |
