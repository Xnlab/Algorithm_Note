# 시각

- **출처**: 이것이 취업을 위한 코딩 테스트다 with 파이썬 (나동빈) — Ch4 구현 예제
- **유형**: 구현 (완전탐색)
- **푼 날짜**: 2026-10-30
- **결과**: 정답

## 문제 요약
0 ≤ N ≤ 23일 때, 00시 00분 00초부터 N시 59분 59초까지의 모든 시각 중 숫자 3이 하나라도 들어간 시각의 개수를 센다.

## 떠올렸어야 할 단서
- 하루는 24 × 60 × 60 = **86,400초**뿐 → 전부 확인해도 충분히 빠르다 → **완전탐색**
- "~가 포함된 경우의 수" → 하나씩 세거나, **전체 − 포함되지 않은 경우**로 셀 수 있다

## 내 풀이

```python
n = int(input())

count = 0

for i in range(n + 1):
    for j in range(60):
        for k in range(60):
            if '3' in str(i) + str(j) + str(k):
                count += 1

print(count)
```

- 시간복잡도: **O(N × 3600)**, 최대 86,400번 반복
- 평가
  - 정답. 시·분·초 3중 반복으로 모든 시각을 만들고 문자열에서 '3'을 찾는, 이 문제의 정석 풀이다.
  - `str(5)`처럼 앞의 0을 붙이지 않아도 되는 이유: 빠진 문자는 '0'뿐이라 '3' 포함 여부에 영향이 없다. 문자열을 이어 붙여도 새로운 숫자가 생기지 않으므로 오판도 없다.
  - 문제의 최대 크기가 작다는 걸 보고 완전탐색을 고른 판단이 핵심.

## 개선된 풀이

N이 작아서 원래 풀이로 충분하지만, 반복을 줄이는 방법도 알아 둔다. 분·초는 매시간 같은 0~59를 반복하니 **한 번만 계산**한다.

```python
n = int(input())

no3 = sum('3' not in str(m) for m in range(60))   # 3이 없는 분(=초)의 수: 45
per_hour = 3600 - no3 * no3                         # 시에 3이 없을 때, 3이 들어간 분·초 조합: 1575

count = 0
for h in range(n + 1):
    count += 3600 if '3' in str(h) else per_hour    # 시에 3이 있으면 그 시간 전체가 해당

print(count)
```

- 시간복잡도: **O(N + 60)** — 3중 반복이 사라짐
- 바뀐 점
  - "3이 포함된 경우 = 전체 − 3이 하나도 없는 경우" (**여사건**)로 세기
  - 분과 초에서 3이 없는 경우를 따로 세어 곱함 (45 × 45). 각 자리가 독립이기 때문에 가능하다.
  - 3, 13, 23시는 분·초와 상관없이 3600개 모두 포함

## 검증
- 책 예제 N = 5 → 두 풀이 모두 `11475`
- N = 0 ~ 23 전부에서 두 풀이가 `HHMMSS`(두 자리 0 채움) 문자열 기준 완전탐색 결과와 일치함을 확인

## 배운 점
- 전체 경우의 수가 **100만 이하**면 먼저 완전탐색을 떠올린다 (Python 1초 ≈ 1,000만~2,000만 연산).
- "~를 포함하는 개수"는 **여사건**(포함하지 않는 개수)을 세는 쪽이 곱셈으로 바로 계산되는 경우가 많다.
