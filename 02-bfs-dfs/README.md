# 02. BFS · DFS · 백트래킹

## 핵심 아이디어
- **BFS**: 가까운 곳부터 넓게. 가중치가 없으면 처음 도착한 거리가 최단 거리.
- **DFS**: 한 길을 끝까지. 연결 요소, 경로 탐색에 사용.
- **백트래킹**: DFS로 모든 경우를 만들되, 안 되는 가지는 일찍 자른다.

## 이런 문제에서 쓴다
- "최소 몇 번 만에", "최단 거리" + 가중치 없음 → **BFS**
- 섬의 개수, 영역 크기, 연결되어 있는가 → BFS / DFS 아무거나
- N ≤ 10~20, 모든 조합·순열 → **백트래킹** 또는 `itertools`

## 템플릿 → [template.py](template.py)
- 그래프 BFS (거리 배열)
- 격자 BFS
- 반복문 DFS (재귀 깊이 문제 회피)
- 백트래킹 (조합)

## 자주 하는 실수
- BFS에서 **큐에서 꺼낼 때** 방문 처리 → 같은 노드가 여러 번 들어감. **넣을 때** 방문 처리한다.
- `list.pop(0)` 사용 → O(n). 반드시 `collections.deque`의 `popleft()`.
- 재귀 DFS에서 `RecursionError` → `sys.setrecursionlimit(10**6)` 또는 반복문 DFS.
- 백트래킹 후 상태 원복을 빼먹음.
