## 문제 요약
N에 "1 빼기" 또는 "K로 나누기(나누어떨어질 때만)"를 반복해 1로 만들 때, 최소 연산 횟수를 구한다. (2 ≤ K ≤ N)

## 떠올렸어야 할 단서
- K ≥ 2이면 **나누기가 빼기보다 항상 같거나 더 많이 줄인다** → 나눌 수 있으면 무조건 나누는 그리디
- N이 매우 크면 1씩 빼는 반복이 병목 → **빼기를 한 번에 몰아서** 계산

## 내 풀이

```python
n, k = map(int, input().split())
count = 0
while (n > 1):
    if (n % k == 0):
        n //= k
        count += 1
    else:
        n -= 1
        count += 1

print(count)
```

- 시간복잡도: **O(N)** (최악: K > N이면 N−1번 반복)
- 평가: 논리는 정확함. 책 조건(N ≤ 100,000)에서는 충분.

## 개선된 풀이

```python
n, k = map(int, input().split())
count = 0

while n >= k:
    target = (n // k) * k     # n 이하에서 k로 나누어떨어지는 가장 큰 수
    count += n - target       # 거기까지 빼는 횟수를 한 번에 더함
    n = target // k
    count += 1

count += n - 1                # 남은 수를 1까지 빼기
print(count)
```

- 시간복잡도: **O(log N)** — 매 반복마다 n이 K배 이상 줄어듦
- 바뀐 점
  - 1씩 빼던 반복을 `n - target`으로 한 번에 처리
  - `count += 1` 중복 제거, 조건문 괄호 생략 (Python 관례)

## 검증
2 ≤ N < 400, 2 ≤ K ≤ N 모든 경우에서 두 풀이 모두 BFS 완전탐색 결과와 일치함을 확인.

## 배운 점
- 그리디가 맞는지는 "이 선택이 손해를 보는 경우가 있는가?"로 확인한다.
- 같은 연산을 1씩 반복하고 있다면, **몇 번 반복될지 계산해서 한 번에 더할 수 없는지** 먼저 의심한다.
