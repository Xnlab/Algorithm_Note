# 성적이 낮은 순서로 학생 출력하기

- **출처**: 이것이 취업을 위한 코딩 테스트다 with 파이썬 (나동빈) — Ch6 정렬 실전 문제
- **유형**: 정렬 (기준 지정 정렬)
- **푼 날짜**: 2026-11-06
- **결과**: 정답

## 문제 요약
N명(1 ≤ N ≤ 100,000)의 이름과 성적(1 ~ 100)이 주어질 때, 성적이 낮은 학생부터 이름을 공백으로 구분해 출력한다. 성적이 같으면 순서는 자유.

## 떠올렸어야 할 단서
- "~가 낮은 순서로 출력" → **정렬**, 기준이 데이터의 일부(성적) → `key` 지정
- 이름과 성적을 **함께** 들고 다녀야 함 → 튜플 `(이름, 성적)`로 묶어 저장
- N ≤ 100,000 → O(N log N) 정렬로 충분 (성적 범위가 1~100으로 작아서 계수 정렬도 가능)

## 내 풀이

```python
n = int(input())
array = []
for i in range(n):
    input_data = input().split()
    array.append((input_data[0], int(input_data[1])))

array = sorted(array, key=lambda student: student[1])

for student in array:
    print(student[0], end=' ')
```

- 시간복잡도: **O(N log N)**
- 평가
  - 정답. 책 풀이와 같은 방식이다.
  - 성적을 `int`로 바꿔 저장한 것이 핵심. 문자열 그대로 정렬하면 `"100" < "95"`가 되어 순서가 틀린다.
  - `key`에 람다를 써서 튜플의 두 번째 값으로 정렬하는 표현이 정확하다.

## 해설

### 데이터를 튜플로 묶는 이유
- 정렬은 성적으로 하지만 출력은 이름으로 한다. 둘을 따로 리스트에 두면 성적을 정렬할 때 이름이 따라오지 않는다.
- `(이름, 성적)` 튜플 하나로 묶으면 정렬할 때 **한 학생의 정보가 통째로** 움직인다.
- `input().split()` → `['홍길동', '95']`. 첫 번째는 문자열 그대로, 두 번째는 `int()`로 변환한다.

### `key=lambda student: student[1]`
- `key`는 "각 원소에서 **무엇을 기준으로** 비교할지"를 돌려주는 함수다.
- `lambda student: student[1]`은 원소(튜플)를 받아 두 번째 값(성적)을 돌려준다. 즉 성적끼리만 비교한다.
- 같은 뜻의 일반 함수:
  ```python
  def setting(data):
      return data[1]
  array = sorted(array, key=setting)
  ```
- 기준이 여러 개면 튜플을 돌려준다. 예: 성적 오름차순, 같으면 이름 사전순 → `key=lambda s: (s[1], s[0])`. 내림차순은 숫자에 `-`를 붙이거나 `reverse=True`.

### 문자열 숫자를 정렬하면 안 되는 이유
- 문자열은 **앞 글자부터** 사전순으로 비교한다. `"100"`과 `"95"`는 첫 글자 `'1'` < `'9'`라서 `"100"`이 앞에 온다.
- 그래서 숫자 비교가 필요한 값은 반드시 `int()`로 바꿔서 저장한다.

### `sorted()`와 `.sort()`
| | `sorted(array, key=...)` | `array.sort(key=...)` |
|---|---|---|
| 결과 | **새 리스트**를 돌려줌 | 원래 리스트를 **제자리에서** 바꿈, `None` 반환 |
| 사용 | `array = sorted(array, ...)` | `array.sort(...)` |
- 이 문제처럼 원래 순서가 필요 없으면 `array.sort(key=lambda s: s[1])` 한 줄로 써도 된다. `array = array.sort(...)`처럼 쓰면 `array`가 `None`이 되니 주의.

### 성적이 같을 때의 순서
- Python의 정렬은 **안정 정렬(stable sort)**이다. 기준값이 같으면 **입력 순서가 그대로 유지**된다.
- 예: `A 50 / B 30 / C 50` → `B A C` (A와 C는 입력 순서대로)
- 이 문제는 동점 순서가 자유라 상관없지만, "같으면 먼저 입력된 순서대로" 같은 조건이 붙은 문제에서는 이 성질 덕분에 별도 처리가 필요 없다.

### 출력 `end=' '`
- `print`는 기본적으로 끝에 줄바꿈을 붙인다. `end=' '`로 바꾸면 이름이 한 줄에 공백으로 이어진다.
- 마지막에 공백이 하나 더 붙지만 대부분의 채점 시스템(백준, 프로그래머스 등)은 줄 끝 공백을 무시한다.
- 같은 출력을 한 번에: `print(' '.join(s[0] for s in array))` — 마지막 공백도 없고, N이 클 때 `print`를 N번 부르는 것보다 빠르다.

### 입력이 많을 때
- N이 최대 100,000이라 `input()`을 10만 번 부른다. 백준처럼 입력이 큰 환경에서는 맨 위에 다음 두 줄을 넣는 습관을 들인다.
  ```python
  import sys
  input = sys.stdin.readline
  ```
- `readline`은 끝의 줄바꿈 문자를 남기지만, 이 문제는 `split()`이 줄바꿈까지 지워 주므로 그대로 써도 된다.

## 검증
- 책 예제 `홍길동 95 / 이순신 77` → `이순신 홍길동`
- 1 ≤ N ≤ 30, 무작위 이름·성적 3,000개 입력에서 성적 기준 정렬 결과와 출력 순서 일치
- 동점 `A 50 / B 30 / C 50` → `B A C` (입력 순서 유지)
- N = 100,000 입력 → 약 0.2초

## 배운 점
- 여러 값을 가진 데이터를 정렬할 때는 **튜플로 묶고 `key`로 기준을 고른다.**
- 숫자 기준 정렬이면 저장할 때 `int()`로 바꾼다. 문자열 숫자는 사전순으로 비교된다.
- Python 정렬은 안정 정렬이라 기준값이 같으면 입력 순서가 유지된다.
