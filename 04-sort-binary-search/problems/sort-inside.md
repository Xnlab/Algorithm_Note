# 내림차순으로 자릿수 정렬하기 (백준 1427 소트인사이드)

- **출처**: Do it! 알고리즘 코딩테스트 with 파이썬 — 선택 정렬 / 백준 1427
- **유형**: 정렬 (선택 정렬 직접 구현)
- **푼 날짜**: 2026-11-23
- **결과**: 오답 (정렬은 맞지만 자릿수를 한 줄에 하나씩 출력)

## 문제 요약
자연수 N(≤ 1,000,000,000)의 각 자릿수를 **내림차순**으로 정렬한 수를 출력한다. 예: `2143` → `4321`

## 떠올렸어야 할 단서
- 자릿수는 최대 10개 → O(N²) 정렬도 충분. 이 문제는 **선택 정렬**을 직접 구현해 보는 연습
- 숫자를 문자열로 받으면 `list(input())`로 자릿수가 바로 나뉜다
- 출력은 **수 하나** → 자릿수를 이어서 한 줄에

## 내 풀이

```python
a = list(input())

for i in range(len(a)):
    max = i
    for j in range(i+1, len(a)):
        if a[j] > a[max]:
            max = j
    
    if a[i] < a[max]:
        temp = a[i]
        a[i] = a[max]
        a[max] = temp

for i in range(len(a)):
    print(a[i])
```

- 시간복잡도: **O(L²)** (L = 자릿수 ≤ 10)
- 평가
  - **정렬은 정확하다.** 선택 정렬 구조(남은 구간에서 최댓값 위치 찾기 → 맨 앞과 교환)가 책 풀이와 같다.
  - **버그 1개 (출력)**: `print(a[i])`가 자릿수마다 줄을 바꿔서 `4321`이 아니라 `4 / 3 / 2 / 1` 네 줄로 나온다.
  - 주의: 변수 이름 `max`가 내장 함수를 덮어쓴다 ([버블 정렬 프로그램 1](bubble-sort-1.md)과 같은 경우). `max_idx`처럼 쓰면 안전하다.

## 정답 풀이 (책 풀이 방식)

내 풀이에서 출력만 한 줄로 바꾼 코드.

```python
a = list(input())

for i in range(len(a)):
    max_idx = i                              # 남은 구간 [i, 끝]에서 가장 큰 값의 위치
    for j in range(i + 1, len(a)):
        if a[j] > a[max_idx]:
            max_idx = j
    if a[i] < a[max_idx]:                    # 더 큰 값이 있으면 i 자리로 가져옴
        a[i], a[max_idx] = a[max_idx], a[i]

print(''.join(a))                            # 한 줄에 이어서 출력
```

- `print(a[i], end='')`로 반복해도 같은 결과.

## `sorted(a, reverse=True)`로 해도 될까?
**된다.** 실전에서는 이게 정답이다.

```python
print(''.join(sorted(input(), reverse=True)))
```

- `sorted`는 문자열도 받아서 **문자 하나하나를 정렬한 리스트**를 돌려준다. `reverse=True`로 내림차순.
- 선택 정렬 버전과 무작위 3,000개에서 결과가 모두 같았다.
- 이 문제가 선택 정렬로 나온 건 **원리 연습** 때문이다. 정렬 과정 자체를 묻는 문제가 아니라면 `sort()` / `sorted()`를 쓴다.

## 해설

### 선택 정렬의 원리
- 남은 구간에서 **가장 큰(작은) 값을 골라(select)** 구간 맨 앞으로 보낸다. 이걸 앞에서부터 한 칸씩 반복한다.
- i번째 회차가 끝나면 0 ~ i번 자리는 확정된다.

| 회차 i | 남은 구간 | 고른 최댓값 | 교환 후 |
|---|---|---|---|
| 0 | 2 1 4 3 | 4 (위치 2) | **4** 1 2 3 |
| 1 | 1 2 3 | 3 (위치 3) | 4 **3** 2 1 |
| 2 | 2 1 | 2 (위치 2) | 4 3 **2** 1 (교환 없음) |
| 3 | 1 | 1 | 4 3 2 **1** |

### 버블 정렬과 비교

| | 버블 정렬 | 선택 정렬 |
|---|---|---|
| 방법 | 이웃끼리 비교해 바꾸며 큰 값을 **뒤로 밀어냄** | 남은 구간에서 최댓값을 **찾아서** 한 번에 앞으로 |
| 한 회차의 교환 | 여러 번 | **최대 1번** |
| 비교 횟수 | O(N²) | O(N²) |
| 같은 값 순서 유지 | 유지됨 (안정) | 깨질 수 있음 (불안정) |

### 문자 그대로 비교해도 되는 이유
- `a`의 원소는 `'2'`, `'1'` 같은 **문자열**이다. 문자열은 사전순으로 비교한다.
- 한 글자 숫자 `'0'` ~ `'9'`는 사전순 = 숫자 크기 순이라 `'9' > '1'`이 참이다. 그래서 `int`로 바꾸지 않아도 된다.
- 단, 두 자리 이상 문자열끼리는 다르다: `'10' > '9'`는 **거짓** ([성적 순 출력](low-score-order.md)에서 본 함정). 이 문제는 한 글자씩이라 안전하다.

## 검증
- 예제 `2143` → 원래 코드는 4줄 출력, 정답 풀이·`sorted` 한 줄 모두 `4321`
- 1 ~ 10억 사이 무작위 3,000개에서 정답 풀이·`sorted` 한 줄 모두 기대값과 일치

## 배운 점
- 선택 정렬: 남은 구간의 최댓값(최솟값)을 찾아 맨 앞과 교환. 회차마다 교환은 최대 1번.
- 정렬 원리를 묻지 않으면 `sorted(..., reverse=True)` 한 줄.
- 출력 형식을 마지막에 다시 확인한다. 리스트를 한 줄로 이어 출력할 땐 `''.join(...)`.
