## 문제 요약
서로 다른 정수 N개(N ≤ 1,000, 절댓값 ≤ 1,000)를 오름차순으로 정렬해 한 줄에 하나씩 출력한다.

## 떠올렸어야 할 단서
- N ≤ 1,000 → O(N²) = 약 100만 번이라 **직접 짠 O(N²) 정렬**도 충분
- 실전에서는 `sort()` 한 줄이면 되지만, 이 문제는 **버블 정렬의 원리를 직접 구현**해 보는 연습

## 내 풀이

```python
n = int(input())
a = [0] * n

for i in range(n):
    a[i] = int(input())

for i in range(n - 1):
    for j in range(n - 1 - i):
        if a[j] > a[j+1]:
            temp = a[j]
            a[j] = a[j+1]
            a[j+1] = temp

for i in range(n):
    print(a[i])
```

- 시간복잡도: **O(N²)** (비교 횟수 N(N−1)/2, N = 1,000이면 499,500번)
- 평가
  - 정답. 책 풀이와 같은 방식이다.
  - 바깥 반복 `n - 1`회, 안쪽 반복 범위 `n - 1 - i`로 **이미 자리 잡은 뒤쪽을 다시 보지 않는** 부분까지 정확하다.

## 해설

### 버블 정렬의 원리
- **이웃한 두 수**를 비교해서 앞이 더 크면 자리를 바꾼다. 이걸 처음부터 끝까지 한 번 훑으면, **가장 큰 수가 맨 뒤로** 밀려난다 (거품이 위로 떠오르듯).
- 한 회차가 끝날 때마다 맨 뒤에 한 개씩 자리가 확정된다. N − 1회 반복하면 전부 정렬된다.

### 반복 범위가 이렇게 되는 이유

| 코드 | 뜻 |
|---|---|
| `for i in range(n - 1)` | 회차. N − 1번이면 충분 (마지막 하나는 저절로 맨 앞에 남음) |
| `for j in range(n - 1 - i)` | 이번 회차에 비교할 위치. `a[j]`와 `a[j+1]`을 비교하므로 j는 최대 `n - 2 - i` |
| `- i` | i회차까지 끝났으면 맨 뒤 i개는 이미 확정 → 다시 볼 필요 없음 |

- `n - 1 - i`에서 `- 1`을 빼먹으면 `a[j+1]`이 마지막에 범위를 넘어 `IndexError`가 난다.

### 자리 바꾸기
```python
temp = a[j]          # 1. 앞 값을 잠깐 보관
a[j] = a[j+1]        # 2. 뒤 값을 앞으로
a[j+1] = temp        # 3. 보관한 값을 뒤로
```
- Python에서는 한 줄로도 쓸 수 있다: `a[j], a[j+1] = a[j+1], a[j]`
  - 오른쪽이 먼저 `(뒤 값, 앞 값)` 묶음으로 계산된 뒤 왼쪽에 한꺼번에 들어가서, `temp` 없이도 값이 섞이지 않는다.

### 예제 따라가기 (`5 2 3 4 1`)

| 회차 | 끝난 뒤 | 확정된 뒤쪽 |
|---|---|---|
| 1 | 2 3 4 1 **5** | 5 |
| 2 | 2 3 1 **4 5** | 4 5 |
| 3 | 2 1 **3 4 5** | 3 4 5 |
| 4 | **1 2 3 4 5** | 전부 |

- 1회차 안쪽: (5, 2) 교환 → (5, 3) 교환 → (5, 4) 교환 → (5, 1) 교환. 5가 한 칸씩 끝까지 밀려난다.
- 작은 수 1은 회차마다 **한 칸씩만** 앞으로 온다. 그래서 맨 뒤에 있던 작은 수 하나 때문에 N − 1회를 다 돌아야 할 수 있다.

### 참고: 일찍 끝내기
- 한 회차 동안 **교환이 한 번도 없었다면** 이미 정렬된 것이므로 멈춰도 된다.
  ```python
  for i in range(n - 1):
      swapped = False
      for j in range(n - 1 - i):
          if a[j] > a[j+1]:
              a[j], a[j+1] = a[j+1], a[j]
              swapped = True
      if not swapped:
          break
  ```
- 이미 정렬된 입력이면 1회차 만에 끝난다. 최악은 여전히 O(N²).

### 실전에서는
- 정렬 자체가 목적이면 `a.sort()` (O(N log N))를 쓴다. N이 100만이어도 빠르다.
- 버블 정렬을 직접 짜 보는 이유는 **"이웃끼리 비교해서 바꾸는 횟수"** 같은 원리를 묻는 문제(예: 버블 정렬이 몇 회차에 끝나는가)에 대비하기 위해서다.

## 검증
- 예제 `5 2 3 4 1` → `1 2 3 4 5`
- 길이 1 ~ 30 무작위 2,000개에서 `sorted()` 결과와 일치
- N = 1,000 → 로컬 약 0.06초

## 배운 점
- 버블 정렬: 이웃끼리 비교·교환 → 한 회차마다 가장 큰 수가 맨 뒤로. 안쪽 범위는 `n - 1 - i`.
- Python 교환은 `a[j], a[j+1] = a[j+1], a[j]` 한 줄.
- O(N²) 정렬은 N ≤ 수천까지만. 그 이상은 `sort()`.
