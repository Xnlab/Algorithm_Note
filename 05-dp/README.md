# 05. DP (동적 계획법)

## 핵심 아이디어
큰 문제를 작은 문제로 나누고, **작은 문제의 답을 저장해 재사용**한다.
풀이 순서는 항상 같다:
1. `dp[i]`가 **무엇을 의미하는지** 한 문장으로 정의
2. 점화식 세우기 (`dp[i]`를 이전 값으로 표현)
3. 초기값 정하기
4. 계산 순서 정하기 (작은 i부터)

## 이런 문제에서 쓴다
- 경우의 수를 묻고 "1,000,000,007로 나눈 나머지" → 거의 DP
- 계단 오르기, 타일 채우기, 최대 합 경로
- 배낭 (무게 제한 + 가치 최대)
- 최장 증가 부분 수열(LIS), 최장 공통 부분 수열(LCS)
- 그리디로 풀다가 반례가 나옴

## 템플릿 → [template.py](template.py)
- 0/1 배낭 (1차원 배열)
- LIS O(n log n)
- LCS
- 2차원 격자 최소 비용 경로

## 자주 하는 실수
- `dp` 정의를 안 쓰고 바로 점화식부터 세움 → 정의가 흔들림
- 0/1 배낭 1차원 배열에서 무게를 **정방향**으로 돌림 → 같은 물건을 여러 번 담게 됨. **역방향**으로 돈다.
- mod 연산을 마지막에만 함 → 중간 값이 커져 느려짐. 매번 `% MOD`.
- 초기값(dp[0], dp[1])을 빼먹음

## 대표 문제
| 문제 | 떠올렸어야 할 단서 |
|---|---|
| 백준 2579 계단 오르기 | 이전 선택이 다음에 영향 → dp[i] = i번째까지 최대 점수 |
| 백준 12865 평범한 배낭 | 무게 제한 + 가치 최대 → 배낭 |

| 백준 9251 LCS | 두 문자열의 공통 부분 → 2차원 DP |
| 프로그래머스 등굣길 | 격자 경로 수 + mod → 2차원 DP |
