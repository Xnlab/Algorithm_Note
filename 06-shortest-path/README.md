# 06. 최단 경로

## 핵심 아이디어
| 상황 | 알고리즘 | 복잡도 |
|---|---|---|
| 가중치 없음 (모두 1) | BFS ([02](../02-bfs-dfs/)) | O(V + E) |
| 가중치 0 또는 1 | 0-1 BFS (덱) | O(V + E) |
| 가중치 양수, 한 출발점 | **다익스트라** | O(E log V) |
| 모든 쌍, V ≤ 500 | **플로이드-워셜** | O(V³) |
| 음수 가중치 있음 | 벨만-포드 | O(VE) — 코테에선 드묾 |

## 이런 문제에서 쓴다
- 도시, 노드, 간선 + "비용", "시간"이 붙은 최단 거리
- 특정 지점을 반드시 거쳐야 함 → 다익스트라를 여러 번 (출발→경유, 경유→도착)
- 모든 노드 사이 거리, 노드 수가 작음 → 플로이드-워셜

## 템플릿 → [template.py](template.py)
- 다익스트라 (heapq)
- 플로이드-워셜
- 0-1 BFS

## 자주 하는 실수
- 다익스트라에서 `if d > dist[cur]: continue`를 빼먹음 → 시간 초과
- 플로이드-워셜 반복 순서를 `i, j, k`로 씀 → **경유지 k가 가장 바깥**
- 무방향 그래프인데 간선을 한쪽만 추가함
- `INF`를 너무 작게 잡음 → `float('inf')` 또는 `10**18`

## 대표 문제
| 문제 | 떠올렸어야 할 단서 |
|---|---|
| 백준 1753 최단경로 | 한 출발점, 양수 가중치 → 다익스트라 |
| 백준 1504 특정한 최단 경로 | 반드시 거칠 노드 → 다익스트라 3번 |
| 백준 11404 플로이드 | 모든 쌍, N ≤ 100 → 플로이드-워셜 |
| 백준 13549 숨바꼭질 3 | 순간이동 비용 0 → 0-1 BFS |
| 프로그래머스 합승 택시 요금 | 경유 지점 전부 시도 → 플로이드 또는 다익스트라 3번 |
