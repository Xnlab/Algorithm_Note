# 07. 유니온 파인드 · MST · 위상 정렬

## 핵심 아이디어
- **유니온 파인드**: 원소들이 어느 그룹에 속하는지 빠르게 합치고 확인. 경로 압축 + 랭크로 거의 O(1).
- **MST (크루스칼)**: 간선을 비용 순으로 정렬 → 사이클이 안 생기면(유니온 파인드로 확인) 선택.
- **위상 정렬**: 진입 차수가 0인 노드부터 큐에 넣어 처리. 선후 관계가 있는 작업의 순서.

## 이런 문제에서 쓴다
- "친구의 친구", 그룹 합치기, 같은 집합인가 → 유니온 파인드
- 무방향 그래프 사이클 판별 → 유니온 파인드
- 모든 도시를 최소 비용으로 연결 → MST
- "A를 하려면 B를 먼저", 선수 과목, 빌드 순서 → 위상 정렬

## 템플릿 → [template.py](template.py)
- 유니온 파인드 (경로 압축 + 크기 기준 합치기)
- 크루스칼 MST
- 위상 정렬 (사이클이면 빈 리스트)

## 자주 하는 실수
- `find`에서 경로 압축을 안 해서 시간 초과
- 재귀 `find`의 깊이 초과 → 반복문으로 작성
- `parent[a] == parent[b]`로 같은 그룹인지 판단 → **반드시 `find(a) == find(b)`**
- MST에서 간선 수가 `V - 1`개가 되면 멈추지 않아도 되지만, 연결이 안 된 경우 확인 필요
- 위상 정렬 결과 길이가 N보다 작으면 사이클이 있다는 뜻
