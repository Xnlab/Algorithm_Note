# 08. 투 포인터 · 슬라이딩 윈도우 · 누적합

## 핵심 아이디어
- **누적합**: `prefix[i] = arr[0] + ... + arr[i-1]`을 미리 구해 두면 구간 합을 O(1)에.
- **투 포인터**: 두 인덱스를 한 방향으로만 움직여 O(n²)을 O(n)으로.
- **슬라이딩 윈도우**: 길이가 고정된(또는 조건을 만족하는) 연속 구간을 밀면서 계산.

## 이런 문제에서 쓴다
- 구간 합 질의가 여러 번 → 누적합 (2차원이면 2차원 누적합)
- 합이 S 이상인 가장 짧은 연속 구간 → 투 포인터 (원소가 양수일 때)
- 정렬된 배열에서 두 수의 합이 X → 양 끝 투 포인터
- 연속 K일 최대 합 → 슬라이딩 윈도우
- 합이 K인 연속 부분 배열 개수 (음수 포함) → 누적합 + 딕셔너리

## 템플릿 → [template.py](template.py)
- 1차원 / 2차원 누적합
- 합이 S 이상인 최소 길이 (투 포인터)
- 정렬 배열 두 수의 합
- 합이 K인 부분 배열 개수 (누적합 + 해시)

## 자주 하는 실수
- 누적합 인덱스를 1칸 밀지 않아서 `prefix[l-1]`에서 음수 인덱스 발생 → **크기 n+1, prefix[0] = 0**
- 음수가 섞인 배열에 투 포인터 사용 → 단조성이 깨짐. 누적합 + 해시로.
- 2차원 누적합에서 겹치는 부분을 한 번만 빼거나 더하지 않음
