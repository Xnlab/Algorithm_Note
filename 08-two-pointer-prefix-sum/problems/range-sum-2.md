# 구간 합 구하기 2 (백준 11660 구간 합 구하기 5)

- **출처**: Do it! 알고리즘 코딩테스트 with 파이썬 — 구간 합 / 백준 11660
- **유형**: 2차원 누적합
- **푼 날짜**: 2026-11-11
- **결과**: 책 풀이를 옮겨 이해한 뒤, 입력 방식만 내 방식으로 바꿈

## 문제 요약
N×N 표(N ≤ 1,024)가 주어지고, (x1, y1)부터 (x2, y2)까지 직사각형 안의 합을 묻는 질의가 M개(M ≤ 100,000) 들어올 때 각 질의의 답을 출력한다. 좌표는 1부터 시작한다.

## 떠올렸어야 할 단서
- **같은 표에 직사각형 합 질의가 여러 번** → 매번 더하면 질의 하나에 최대 100만 칸 → 불가능
- 1차원 구간 합([구간 합 구하기 1](range-sum-1.md))의 2차원 버전 → **2차원 누적합**
- 좌표가 1부터 시작 + 공식에 `i-1`, `j-1`이 들어감 → **0번 줄·0번 칸을 0으로 깔아 둔다**

## 내 풀이

책 풀이에서 줄 입력 부분만 `list(map(...))` 형식으로 바꾼 코드.

```python
import sys
input = sys.stdin.readline
n, m = map(int, input().split())
A = [[0] * (n + 1)]
D = [[0] * (n + 1) for _ in range(n + 1)]

for i in range(n):
    A.append([0] + list(map(int, input().split())))

for i in range(1, n + 1):
    for j in range(1, n + 1):
        D[i][j] = D[i][j-1] + D[i-1][j] - D[i-1][j-1] + A[i][j]

for _ in range(m):
    x1, y1, x2, y2 = map(int, input().split())
    result = D[x2][y2] - D[x1-1][y2] - D[x2][y1-1] + D[x1-1][y1-1]
    print(result)
```

- 시간복잡도: **O(N² + M)** (누적합 표 만들기 N², 질의마다 O(1))
- 책 코드를 옮겨 적을 때 생긴 오타 두 개 (고친 상태로 위에 기록)
  - `D = [[0] * (n + 1)] for ...]` — `]`가 하나 더 있어 `SyntaxError`
  - `D[x-1][y-1]` — 없는 변수 `x`, `y` → `NameError`. 올바른 값은 `D[x1-1][y1-1]`

## 해설

### 1. A와 D 선언

```python
A = [[0] * (n + 1)]                          # 0번 줄 하나만 들어 있는 2차원 리스트
D = [[0] * (n + 1) for _ in range(n + 1)]    # (n+1)×(n+1) 전부 0
```

- `[0] * (n + 1)` → `[0, 0, 0, 0, 0]` (n = 4). 리스트의 `*`는 **내용물을 반복해 이어 붙인다** (`[0] + [0] + [0] + [0] + [0]`).
- 그걸 `[ ]`로 한 번 더 감싸면 "줄이 하나뿐인 2차원 리스트" → A의 **0번 줄**.
- A와 D를 다르게 만드는 이유는 **채우는 방식이 달라서**:
  - A는 `append`로 줄을 **뒤에 붙여 가며** 채운다 → 처음엔 0번 줄만 있으면 된다.
  - D는 `D[i][j] = ...`처럼 **자리를 지정해서** 넣는다 → 그 자리가 미리 있어야 하므로 전체 크기로 만든다.

#### `A = []`나 `D = []`로 시작하면?
| 바꾼 것 | 결과 | 이유 |
|---|---|---|
| `A = []` | `IndexError` | 첫 입력 줄이 `A[0]`이 되어 줄 번호가 하나씩 밀림. `A[n]`이 존재하지 않음 |
| `D = []` | `IndexError` | 빈 리스트에는 `D[1][1]` 같은 자리가 없어 값을 넣을 수 없음 |

→ A는 **0번 줄을 미리 넣고**, D는 **전체 크기로 미리 만드는** 것이 필요하다.

#### 2차원 리스트를 `*`로 만들면 안 되는 이유
```python
D = [[0] * 4] * 4      # 네 줄이 모두 같은 리스트(같은 주소)
D[0][0] = 9            # → 네 줄 모두 맨 앞이 9가 됨
```
- 바깥 `*`는 줄을 복사하지 않고 **같은 줄을 4번** 넣는다 (`id(D[0]) == id(D[1])`).
- 안쪽 `[0] * 4`는 괜찮다. 정수는 바꿀 수 없는 값이라 `D[0][0] = 9`가 칸의 값을 **새 값으로 교체**할 뿐, 다른 칸에 영향이 없다.
- 규칙: **숫자를 반복할 땐 `*`, 줄(리스트)을 여러 개 만들 땐 `for`**.

### 2. 한 줄 입력 `A.append([0] + list(map(int, input().split())))`

입력 `1 2 3 4` 기준:

| 단계 | 코드 | 결과 |
|---|---|---|
| ① | `input().split()` | `['1', '2', '3', '4']` |
| ② | `list(map(int, ...))` | `[1, 2, 3, 4]` |
| ③ | `[0] + ...` | `[0, 1, 2, 3, 4]` — 리스트 `+`는 이어 붙이기 |
| ④ | `A.append(...)` | A의 다음 줄로 추가 |

- 책의 `[int(x) for x in input().split()]`(리스트 컴프리헨션)과 ②의 결과는 똑같다.
- 맨 앞 0이 **0번 칸** 역할을 한다. `[0] +`를 빼면 칸 번호가 하나씩 밀려 `A[i][n]`에서 `IndexError`.

완성된 A (예제):
```
0 0 0 0 0      ← 처음에 넣어 둔 0번 줄
0 1 2 3 4      ← 맨 앞 0은 [0] + 로 붙인 0번 칸
0 2 3 4 5
0 3 4 5 6
0 4 5 6 7
```

### 3. 0번 줄·0번 칸이 하는 일
- 공식에 `D[i-1][...]`, `D[...][j-1]`이 들어간다. i = 1 또는 j = 1이면 이 값은 0번 줄·칸 → **0이라서 영향 없음**.
- 0번 줄·칸이 없으면 인덱스가 −1이 되는데, Python의 `리스트[-1]`은 **맨 마지막 값**이라 오류 없이 답만 틀린다.
- 즉 0 패딩은 **경계 if문을 없애 주는 장치**다. 패딩 없이 풀려면 "위쪽이 있을 때만 더한다" 같은 if문이 D 계산에 3개, 질의에 3개 필요하다.

### 4. 누적합 표 D: `D[i][j] = D[i][j-1] + D[i-1][j] - D[i-1][j-1] + A[i][j]`

`D[i][j]` = (1, 1)부터 (i, j)까지 직사각형의 합

```
        j-1  j
     ┌──────┬───┐
     │  ③   │ ② │     D[i][j-1]   = 왼쪽 덩어리 (① + ③)
 i-1 │      │   │     D[i-1][j]   = 위쪽 덩어리 (② + ③)
     ├──────┼───┤     D[i-1][j-1] = ③, 위 두 덩어리에 모두 포함 → 한 번 빼기
  i  │  ①   │ ★ │     A[i][j]     = ★ 지금 칸
     └──────┴───┘
```

예: `D[2][3]` = (1+2+3) + (2+3+4) = 15
```
D[2][2] + D[1][3] - D[1][2] + A[2][3]
=   8   +   6     -   3     +   4      = 15
```

- 반복문이 위 줄부터, 왼쪽 칸부터 돌기 때문에 공식에 쓰는 세 값은 항상 이미 계산되어 있다.

완성된 D (예제):
```
0  0  0  0  0
0  1  3  6 10
0  3  8 15 24
0  6 15 27 42
0 10 24 42 64     ← D[4][4] = 전체 합
```

### 5. 질의: `D[x2][y2] - D[x1-1][y2] - D[x2][y1-1] + D[x1-1][y1-1]`

```
          y1-1  y1      y2
       ┌───────┬─────────┐
       │   ④   │    ②    │   D[x1-1][y2]   = ② + ④  (위쪽 띠)
  x1-1 │       │         │
       ├───────┼─────────┤   D[x2][y1-1]   = ③ + ④  (왼쪽 띠)
  x1   │   ③   │  원하는  │
       │       │   영역   │   D[x1-1][y1-1] = ④      (두 번 빠진 모서리 → 되돌리기)
  x2   │       │         │
       └───────┴─────────┘   D[x2][y2]     = 전체
```

예: `2 2 3 4` → 영역 `3 4 5 / 4 5 6` = 27
```
D[3][4] - D[1][4] - D[3][1] + D[1][1]
=  42   -   10    -    6    +    1    = 27
```

- D를 만들 때와 질의할 때 모두 원리는 같다: **두 번 더했거나 두 번 뺀 부분을 한 번 되돌린다.**

## 검증
- 백준 11660 예제 → `27 6 64`
- 1 ≤ N ≤ 7, 무작위 표·질의 300세트에서 직접 더한 값과 일치
- `A = []` 또는 `D = []`로 바꾸면 `IndexError` 확인
- N = 1,024, M = 100,000 → 로컬 약 0.7초

## 배운 점
- 2차원 누적합: **만들 때는 왼쪽 + 위 − 겹친 부분 + 지금 칸, 질의할 때는 전체 − 위 − 왼쪽 + 겹친 부분.**
- 1부터 시작하는 좌표 + `i-1` 공식 → 0번 줄·칸을 0으로 깔아서 경계 if문을 없앤다. 입력을 받는 방식(`list(map(...))`, 리스트 컴프리헨션)은 자유지만 **맨 앞 `[0] +`는 필수**.
- `append`로 채울 리스트는 시작 줄만, 인덱스로 채울 리스트는 전체 크기로 미리 만든다.
- 리스트 `*`는 내용물 반복. 2차원 리스트는 `[[0] * m for _ in range(n)]`.
