# 09. 스택 · 큐

## 핵심 아이디어
- **스택**: 나중에 넣은 것을 먼저 꺼낸다 (LIFO). Python `list`의 `append` / `pop`.
- **큐**: 먼저 넣은 것을 먼저 꺼낸다 (FIFO). `collections.deque`의 `append` / `popleft`.
- **단조 스택**: 스택 안을 항상 오름차순(또는 내림차순)으로 유지하며, 깨지는 순간 꺼내서 처리. "오른쪽/왼쪽에서 처음 나오는 더 큰(작은) 값"을 O(N)에.

## 이런 문제에서 쓴다
- 괄호 짝 맞추기, 가장 최근 것과 비교 → **스택**
- 1부터 순서대로 넣고 빼서 수열 만들기 → **스택**
- "오른쪽에서 처음 나오는 더 큰 수", 탑의 신호, 히스토그램 → **단조 스택**
- 줄 서기, 순서대로 처리, 카드 돌리기, BFS → **큐(deque)**

## 템플릿 → [template.py](template.py)
- 괄호 검사 (스택)
- 오큰수 (단조 스택)
- 카드 버리고 아래로 보내기 (큐)

## 자주 하는 실수
- 빈 스택에서 `pop()` / `stack[-1]` → `IndexError`. **꺼내기 전에 `if stack`**
- 큐를 `list.pop(0)`으로 → O(N)이라 시간 초과. `deque.popleft()`
- 결과를 `print`로 수십만 번 출력 → 느림. 리스트에 모아 `'\n'.join`
- 단조 스택에 **값** 대신 **인덱스**를 넣어야 하는 문제(답을 위치에 적어야 할 때)에서 값을 넣음
