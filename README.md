# Algorithm Note (Python)

코딩테스트 대비 개인 노트. 목표는 **문제를 읽자마자 유형을 떠올리고, 템플릿을 막힘없이 구현하는 것.**

## 사용법

1. 문제를 읽으면 **N의 범위**부터 확인 → 아래 시간복잡도 표로 가능한 알고리즘을 좁힌다.
2. 문제 속 표현을 **신호 인덱스**에서 찾아 유형 폴더로 이동한다.
3. 풀고 나면 해당 유형 README의 `대표 문제`에 "어떤 단서에서 떠올렸어야 했나"를 한 줄 추가한다.
4. 틀렸으면 [mistakes.md](mistakes.md)에 원인을 기록한다.

## 1. 입력 크기 → 시간복잡도

Python은 대략 **1초에 1,000만~2,000만 번 연산**으로 잡는다.

| N의 범위 | 가능한 복잡도 | 떠올릴 알고리즘 |
|---|---|---|
| ~10 | O(n!) | 순열 완전탐색 |
| ~20 | O(2ⁿ) | 부분집합, 백트래킹, 비트마스크 |
| ~500 | O(n³) | 플로이드-워셜, 3중 반복 |
| ~5,000 | O(n²) | 2중 반복, 2차원 DP |
| ~1,000,000 | O(n log n) | 정렬, 이분탐색, 힙, 다익스트라 |
| ~10,000,000 | O(n) | 투 포인터, 누적합, 한 번 순회 |
| 그 이상 | O(log n), O(1) | 이분탐색, 수학 공식 |
